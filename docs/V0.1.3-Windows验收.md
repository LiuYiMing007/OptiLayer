## 实际修复

1. Windows 默认代码页可能破坏 JSON 进程中文通信，明确标准流 UTF-8；测试在 GBK 环境复核。
2. Python 测试及验收脚本显式 UTF-8；报告按版本/平台输出，保留历史证据。
3. npm 锁文件补全 Windows 跨平台可选依赖，未主动升级生产计算依赖。
4. Python 3.13 TemporaryDirectory 的私有 Windows ACL 会使移出的便携目录对桌面用户不可读；打包暂存目录改为正常继承权限，重制后以桌面用户从 F: 运行通过。
5. Windows 默认只打包便携目录，提供微软环境加载脚本；界面与产品版本 0.1.3，Windows 保存提示 Ctrl+S。
