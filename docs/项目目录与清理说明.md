# 项目目录与清理说明

整理日期：2026-10-31。

## 保留内容

- `src/`、`engine/`、`src-tauri/`、`scripts/`、`tests/`、`fixtures/`：源码、构建配置、验证脚本与原始样本。
- `docs/`：更新报告、技术路线、原始实验文件与验收证据。
- `release/`：当前 0.1.3 的 Mac 应用、DMG、Windows 便携目录及便携压缩包。
- `backups/`：合并前的 0.1.2 源码、应用和工作区备份，以及 Windows 源码修改原包。
- `acceptance/`：Windows 回传数据和 Mac 验收副本。
- `.venv/`、`node_modules/`：保留现有开发依赖，避免为清理而破坏开发环境。
- `.dev-data/`、`.local-workspaces/`：含项目数据，未作为缓存删除。

## 位置调整

| 原位置 | 当前位置 |
| --- | --- |
| `TFC-Windows-0.1.3-验收-20261031/Windows/` | `release/Windows/TFC/` |
| 同目录 Windows 便携 ZIP | `release/TFC-0.1.3-Windows-x64-portable.zip` |
| 同目录 Mac 源码修改 ZIP | `backups/windows-0.1.3-source.zip` |
| 同目录 `数据验收/` | `acceptance/Windows-return-0.1.3/` |

Windows 回传工作区现为 `acceptance/Windows-return-0.1.3/搬迁 SSD 模拟/Workspace`；移动后全部文件哈希与清理前相同。Mac 验收副本仍为 `acceptance/Mac-return-0.1.3/搬迁 SSD 模拟/Workspace`。历史验收报告中的绝对路径是当时的证据，保留原值。

## 已移出项目

Rust 构建缓存、Python 打包中间文件、重复引擎、前端构建输出、旧版应用、已完成用途的 0.1.2 Windows 交接包和系统缓存文件已移入 macOS 废纸篓中的专用目录。没有永久清空废纸篓。

项目体积由约 3548 MiB 降至 748 MiB，减少约 2800 MiB。由于文件仍在废纸篓，磁盘空间尚未永久释放。具体清单和恢复位置见 `2026-10-31-项目清理记录.json`。

清理后首次构建会重新生成 Rust/Python 构建缓存，耗时可能增加；已交付的 Mac 与 Windows 运行环境完整保留。
