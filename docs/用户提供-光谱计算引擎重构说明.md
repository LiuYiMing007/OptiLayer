# TFC for Mac：光谱计算引擎重构说明

> 交给 Codex
> 作为光谱计算模块的实现、排错和验收规范。不要为了让曲线"看起来正确"而修正结果，必须让底层物理模型正确。

## 1. 当前问题

当前 4 层 Ta2O5 / SiO2 膜系在 330--450 nm 几乎得到
`T≈100%`、`R≈0%`。截图中 380 nm 为 `T=99.9394%`、`R=0.0606%`。虽然满足
`R+T≈100%`，但能量守恒不能证明算法正确。

请严格按照多层薄膜 TMM（Transfer Matrix Method / Characteristic Matrix
Method）重构和验证计算内核。

## 2. 数据模型

每层至少包含：

``` text
material
physicalThicknessNm
n
k
```

复折射率：

``` text
N(lambda) = n(lambda) - i*k(lambda)
```

第一阶段允许 `n=constant, k=0`，以后再支持 `n(lambda), k(lambda)`。

必须区分物理厚度 `d`、光学厚度 `n*d`、QWOT：

``` text
QWOT = 4*n*d/lambda_ref
d = QWOT*lambda_ref/(4*n)
```

QWOT 不能直接当物理厚度参与相位计算。

## 3. 膜层方向

TFD 中 `LAYER 1` 通常表示靠近基底的一层。若结构为：

``` text
AIR
Layer 4
Layer 3
Layer 2
Layer 1
SUBSTRATE
```

光从 AIR 入射时传播顺序是：

``` text
Layer 4 -> Layer 3 -> Layer 2 -> Layer 1 -> substrate
```

建议明确：

``` text
storageOrder = substrateToIncidentMedium
propagationOrder = incidentMediumToSubstrate
```

不要让 UI 显示顺序决定物理计算顺序。

## 4. 正入射、无吸收 TMM

第一阶段只实现：

``` text
incidenceAngle = 0 deg
k = 0
coherent coating layers
single front coating
no substrate backside
```

第 j 层相位厚度：

``` text
delta_j = 2*pi*N_j*d_j/lambda
```

`d` 与 `lambda` 必须同单位，三角函数使用弧度。

单层特征矩阵：

``` text
M_j = [
  [cos(delta_j),             i*sin(delta_j)/N_j],
  [i*N_j*sin(delta_j),       cos(delta_j)]
]
```

按照光实际传播方向相乘：

``` text
M = M_first * M_second * ... * M_last
```

设：

``` text
M = [[A, B],
     [C, D]]
```

入射介质折射率 `n0`，基底折射率 `ns`：

``` text
X = A + B*ns
Y = C + D*ns

r = (n0*X - Y)/(n0*X + Y)
t = (2*n0)/(n0*X + Y)

R = abs(r)^2
T = real(ns)/real(n0) * abs(t)^2

R_percent = R*100
T_percent = T*100
```

## 5. 能量守恒

无吸收且不考虑基底背面时：

``` text
R + T = 1
energyError = abs(R + T - 1)
```

建议 `energyError < 1e-10`。

注意：`R+T=1` 只是必要条件，不足以证明算法正确。

## 6. Test 1：裸基底 Fresnel

删除全部膜层：

``` text
AIR n0 = 1.0
GLASS ns = 1.52
```

理论：

``` text
R = ((n0-ns)/(n0+ns))^2
```

预期约：

``` text
R = 4.258%
T = 95.742%
```

如果 0 层膜仍得到 `R≈0, T≈100%`，说明 AIR/GLASS
边界条件没有正确进入计算。

## 7. Test 2：单层四分之一波

``` text

AIR n = 1.0
Film n = 2.0
Substrate n = 1.5
QWOT = 1
```

``` text
d = 550/(4*2.0) = 68.75 nm
```

用于检查物理厚度、QWOT 换算、相位、矩阵和边界条件。

## 9. 当前截图的重点排查

截图中参考波长 380 nm。Layer 1 为
`TA2O5_REF, d=9.54 nm, QWOT=0.2109`。若 `n=2.10`：

``` text
4*2.10*9.54/380 ≈ 0.2109
```

Layer 3 `d=66.60 nm, QWOT=1.4722` 也一致。因此 QWOT
显示换算本身基本正常。

优先检查：

1.  TMM 是否真正把所有膜层加入矩阵。
2.  矩阵乘法顺序。
3.  AIR / GLASS 边界条件。
4.  TFD 层序与传播层序。
5.  Swift 复数运算。
6.  `delta` 单位。
7.  R/T 是否错误归一化。
8.  是否误把 QWOT 当 d。
9.  是否存在计算时仍使用默认空膜系的状态同步 bug。

## 11. 架构

不要把公式写进 SwiftUI View：

``` text
UI
|
SpectrumViewModel
|
ThinFilmEngine
|-- MaterialModel
|-- LayerModel
|-- OpticalStack
|-- TMMCalculator
|-- SpectrumCalculator
`-- ValidationTests
```

核心接口：

``` text
calculateSpectrum(stack, wavelengthRange, incidenceAngle, polarization)
calculateRT(stack, wavelength, incidenceAngle, polarization)
```

返回至少包含：

``` text
wavelength
R
T
A
energyError
```

其中：

``` text
A = 1 - R - T
```
