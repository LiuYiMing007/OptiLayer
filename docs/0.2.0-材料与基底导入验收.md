## 校验规则

- 名称带集合命名空间，避免 MATERIAL、SUBSTRAT、SCHOTT、SOPRA 的同名条目互相覆盖。显示名称和原文件相对路径保留。
- 逐项记录原文件 SHA-256、解码方式、原备注；不依赖原 SSD 路径。完整清单见 [来源清单](0.2.0-材料数据清单.json)。
- 表格检查声明点数、点序、列数、有限值、正 n、非负 k、重复波长；按波长排序，只有完全一致的重复行才合并。
- 色散保留全部系数、模型编号、原有效范围；λ 以 μm 代入。当前数据实际使用 n 模型 1/4/5/6、k 模型 1/2，均按原手册定义实现。
- 表格采用 TFCalc 的线性插值与范围外最近端点规则；单点表相当于常数。发生范围外计算时光谱窗口显示提示。公式超出声明范围或当前波长无物理解时明确拒绝计算。
- 部分旧玻璃公式（如 SF11）声明范围在紫外端出现非实数区域。保留原范围与系数、显示提示，在可求实数的可见光区域可用，不擅自修正公式。
- 25 项异常记录进入隔离目录，可检索、查看原因，禁止选入计算。保留原损坏记录用于追溯，不猜测缺失点、不将负 k 改成 0。

## 可借鉴内容与边界

该文件夹主要是原程序的安装文件与数据，不是可重新编译的 TFCalc 源码。仅提取材料／基底数值、格式语义及必要来源备注；不执行、不复制、不发布原 EXE、HLP 或手册。

原目录另有照明谱（ILLUMINA）、探测器响应（DETECTOR）、角度分布（DISTRIBU）、示例膜系与目标。它们适合未来照明／探测加权、示例教学和测试参考。本版只清点其用途，没有将未知语义的数据直接接进计算，也没有新增优化功能。

数学依据：用户提供手册第 2 节 p32–33（线性插值、范围规则与公式定义）；独立对照 [Byrnes 多层膜光学推导](https://arxiv.org/abs/1603.02720) 与 [tmm 0.2.0](https://github.com/sbyrnes321/tmm)。数据源是用户提供的旧材料库，不代表当前厂商重新认证或用户实际沉积工艺的实测值。
