# 0.2.3 光学环境与有限基底设计

## 保留的路径与新增模型

Tauri/React → 工具命令与统一 Project State → Python Optical Core。存储、TFCalc 解析、UI 不实现光学公式。没有重写已验证的单面半无限计算，也没有增加生产依赖。

- 半无限：保留 `engine/optics.py` 的常数无损矩阵和色散/吸收散射递推。T 为进入基底的能流，不含背面返回光。
- 非相干有限基底：前后两组薄膜各自相干，块状基底的往返相位平均，保留传播吸收和强度多次反射。
- 相干有限基底：基底作为有限厚相干层，正背膜系及基底一起计算干涉。该模型需用户自行提供足以解析窄条纹的采样，不以“1 mm”等单一厚度替代相干性判断。

原始 TFCalc 手册把基底视为无干涉的块状介质；导入存在背面层或独立出射介质的 TFD 时默认非相干模型。出射介质与基底相同且无背膜时，按其半无限约定导入。

## 结构与方向

两个膜层数组都从基底向外编号。正面照射的物理顺序是：

`incident → reversed(layers) → substrate → back_layers → exit`

Back 照射反转整个物理结构并从 exit 一侧入射；给定入射角相对于该侧表面法线。各层共享切向波矢 β = n_entry sin θ_entry，不能把外侧的入射角直接当作玻璃内部角度。

半无限 Back 是从基底侧穿过正面膜系到 incident 介质，不附加一个虚构的背面界面。实际入射介质要求无吸收，遇到吸收入射介质明确报错，不能把 k 改为零。

## 计算

新模块 `engine/finite_substrate.py` 使用被动介质 n+ik，选择向前传播/衰减的 γ = sqrt(n²−β²) 分支。相干块采用带指数缩放和逐层幅度归一化的特征矩阵；临界角 γ=0 使用解析极限，避免 0/0。缩放因子精确计入透射系数，不通过裁剪 R/T、归一化能量或设置透射率下限掩盖误差。

非相干基底单程强度衰减：

`P = exp(−4π d Im(γ_substrate) / λ)`，其中 d 与 λ 均为 nm，输入基底厚度由 mm 乘 10⁶ 转换。

用正面块的正向 Rf/Tf、反向 Rr/Tr，背面块的 Rb/Tb 求和：

`D = 1 − Rr Rb P²`

`R = Rf + Tf Tr Rb P² / D`

`T = Tf Tb P / D`

这里反向块使用其正确的入射介质和复折射率能流归一化。无吸收、无传播能流的全反射基底按非相干模型返回前表面反射；若要计算有限间隙的受抑全反射，应选择相干模型。

A = 1−R−T 为原始残差：有限模型包含薄膜及基底吸收；半无限模型只计进入最终介质前的吸收。最终半无限出射介质内部的后续吸收不再计入 A。

解析例：n=1.5 的无损裸玻璃，空气两侧、法向入射，单面半无限 T=96%；非相干整片 T=12/13≈92.3076923%。不能把两者当成同一个量。

依据：[Byrnes, Multilayer optical calculations](https://arxiv.org/abs/1603.02720)，独立开发测试使用 [sbyrnes321/tmm](https://github.com/sbyrnes321/tmm) 的 `coh_tmm` / `inc_tmm`。该测试依赖不参与生产计算。

## 光源与探测器

WHITE / IDEAL 均为平坦 100% 参考。自定义光源以相对强度百分数描述，探测器为 0–100% 效率；波长递增，线性插值，范围外取最近端点。数据随项目保存。

`响应 = 本征光谱 × 光源强度/100 × 探测器效率/100`

单独返回加权数组，图表可切换“响应加权”；统计、分析和能量检查始终使用本征 R/T/A。加权模式隐藏本征目标曲线和 S/P 分量，避免混合不同物理量。CSV 的加权列使用明确列名。

WHITE 不冒充 D65；没有源数据的非 WHITE/IDEAL TFD 响应不能用默认值替代。未实现光源相位、群延迟、探测器空间收集几何或散射模型。
