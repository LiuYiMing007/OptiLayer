# V0.1 范围与验收

目标闭环：打开应用 → 加载四层参考膜系 → 修改膜厚 → 计算光谱 → 保存 → 重新打开并复现。

## 模型边界

常数实数折射率、k = 0、0° 入射、相干单面多层膜；忽略基底背面。不接受非零入射角和吸收材料。材料常数随项目保存。计算按入射方向逆序读取基底到空气的层列表。

## 自动验证

- 参考 CSV 的 301 个采样点分别验证 R/T，误差 ≤ 1e-5 个百分点。
- 无膜层时与空气/玻璃裸界面公式一致。
- 验证能量守恒误差。
- 拒绝无效步长、范围、折射率、非零角度、非零 k 和未知材料。
- 拒绝 TFD 膜层数量不符及未知材料。
- SQLite 保存、覆盖更新、列表、打开后项目数据和重算结果一致。

## 产品行为

- 旧光谱与当前参数不一致时显示过期提示，隐藏当前指标并禁止导出。
- 用户应用新建、导入或打开操作前，提示未保存修改。
- TFD 导入明确提示只支持子集；不静默宣称完整格式兼容。
- 桌面程序使用随应用打包的 Python 引擎。

## 后续版本

真实 TFCalc 文件与导出光谱交叉验证；色散/吸收；斜入射和偏振；目标与优化器；AI 工具调用；实测与工艺系统。
