# 0.1.3 Mac 合并与回传验证

日期：2026-10-31。环境：Apple Silicon macOS（arm64），本机 Python 3.13.7。接收 Windows 0.1.3 源码修改包后，在原 Mac 项目目录中合并并重新构建。

## 备份和合并

修改前备份目录：`backups/pre-0.1.3-merge-20261031-094113/`。

- `Mac源码-0.1.2.zip`：原源码、配置、测试、fixtures、文档；ZIP 完整性检查通过。
- `TFC-0.1.2.app`：原可用 Mac 应用，包含完整引擎环境。
- `Workspace-original-copy/`：Mac 原工作区副本；数据库使用 SQLite backup API 保存一致快照。
- `source-sha256.json`、`original-workspace-hashes.json`、`workspace-selection.json`：合并前文件哈希及本机工作区偏好。
- `incoming-source-review.diff`：接收内容与 Mac 原文件的对比。

回传压缩包中的 31 项文件哈希与其清单逐项一致（另有哈希清单本身，共 32 项）。对照此前发送 Windows 的 0.1.2 源码包，没有本地并行修改冲突。原 Mac `.venv`、`node_modules`、`target` 没有使用 Windows 目录替换；仅按更新锁文件重新安装本机 Node 依赖。

`engine/optics.py`、`models.py`、`analysis.py` 的 SHA-256 与备份一致，计算核心未重写。依赖锁文件没有改变已有依赖版本。

## 验证边界

这次在 Mac 本地读取从 Windows 实际介质回传的 Workspace 副本，完成数据兼容和复算比对；不等同于在当前 Mac 上把同一物理 SSD 来回插拔。当前没有挂载外置 SSD，故没有补做真实换盘符、物理断网、热拔插/异常断电、缺少 WebView2 机器的检查。

本地构建没有 Developer ID 签名及公证。保留 Plotly 体积提示。没有开发 AI Agent、膜系优化、吸收或色散。

## 恢复方式

关闭 TFC 后，将当前源码另行备份，再从 `Mac源码-0.1.2.zip` 恢复原相对路径；合并清单中新增文件需要另行移出保留。将备份 `TFC-0.1.2.app` 复制为 `release/TFC.app` 即可恢复旧应用。原工作区从未替换，通常无需恢复数据；如确需恢复，优先复制备份到新目录，用“打开工作区”读取，避免覆盖唯一数据。
