# 菜单精简预览（基于 0.2.5-dev.2）

此变更仅提供界面预览，未创建新版本标签，未替换 GitHub 的已发布程序包。待用户确认菜单与编辑行为后再决定发布。

## 菜单

- 文件：新建项目、打开项目、保存项目、另存为、导出光谱 CSV，共五项。打开项目直接选择 TFD 或项目 JSON，复用已有解码、导入校验和未保存修改保护；工作区项目列表仍可从项目窗口进入。
- 编辑：撤销膜系修改、重做膜系修改，共两项。当前仍分别表示退回一步、恢复刚撤销的一步。用户还提到回到文件刚打开的状态；这与标准重做含义不同，尚待用户明确后再决定是否将第二项改为恢复初始状态，未暗中改变现有撤销历史逻辑。
- 参数：环境、膜堆表达式、前表面膜层、后表面膜层、组；一条分隔线；材料、基底、光源、探测器。菜单命令沿用原有共享窗口逻辑，前表面入口在重新打开时定位正面。
- 分析：单纯分析、交互式分析、光谱分析。
- 窗口、帮助保留；已迁入参数栏的窗口入口不在窗口栏重复注册。
- 移除膜系、计算、工具三栏及未开发的灰色菜单项。不添加 AI / Agent 功能或占位菜单。

## 跨平台与兼容

macOS 系统菜单和 Windows 独立菜单窗口共用精简配置，浏览器菜单同步。Windows 独立菜单小窗口由 650 缩至 460 逻辑像素宽。macOS 退出保留在系统应用菜单，文本编辑标准动作收在系统应用菜单的文本编辑子菜单，编辑栏仅保留两项膜系操作；保留系统复制、粘贴、文本撤销等快捷键。

工具栏仍可增删、复制和调整膜层。内部命令注册与可见菜单分开，隐藏菜单不会导致已有工具栏操作失效；Mac 上可见菜单快捷键由原生菜单处理，隐藏工具命令由窗口处理，避免重复执行或消失。
