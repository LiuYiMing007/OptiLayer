# 0.1.5 三个代表窗口：工程界面规范

状态：0.1.5-dev.3 视觉与交互预览，等待用户确认。仅覆盖光谱主窗口、膜层结构、计算参数；不自动推广至材料、基底、项目、分析等窗口，不发布正式 0.1.5 标签。

## 现有界面分析与本阶段调整

此前已有真实桌面多窗口及统一项目状态，保留。主要问题是主窗口重复标题、项目说明、图表结果标签和多排辅助区域挤占绘图；膜层每格常驻输入框、材料色点、层号徽章和逐行删除按钮增加噪声；参数双列标签在上、输入在下，缺少连续的属性对齐。

本阶段主窗口只保留两排紧凑命令与曲线控件、一行结果和一行状态，图表占据剩余空间。膜层采用静态单元格 + 当前格编辑器，结构操作集中在工具栏与右键菜单。参数按标签、输入、单位三列排列，不改变计算公式或项目模型。

## 统一规范

| 类别 | 规范 |
| --- | --- |
| 色彩 | 背景 #F3F3F3、白色工作面、边界 #D8D8D8、正文 #242424、辅助 #666666、动作 #3978B8、选择 #DCEAF8 |
| 字体 | 平台系统字体，正文/数值 13px，工具栏/列标题 12px，辅助 11px；数值使用等宽数字 |
| 间距 | 4px 基准，控件间距 4–8px，属性面板边距 12px |
| 控件 | 输入 28px，按钮 27–28px，圆角 2–3px，常态无阴影；弹出菜单允许轻阴影 |
| 表格 | 行高 29px、粘性表头、数值右对齐、选中浅蓝、焦点边框；最多显示 6 位小数并去尾零 |
| 精度 | 展示格式化不写回数据；进入编辑及复制时使用完整数值字符串；无改动退出不反算厚度 |
| 窗口 | macOS 原生菜单、Windows 独立菜单小窗口沿用；工具关闭隐藏，不另建项目副本；位置恢复沿用已有平台布局机制 |
| 图表 | 白色画布、浅细网格、12px 刻度、2px 主曲线；缩放/平移/复位/精确悬停保持可用 |
| 状态 | 未选曲线只淡化，不加删除线；禁用遵循可用性；无效参数框标记，粘贴错误明确提示；历史曲线过期状态保留 |

样式限定在代表窗口；未改全局 NumericInput 或其他工具窗口的编辑语义。计算参数默认高度 560px，仅作用于未保存过布局的窗口，已有布局不覆盖。

## Chart Theme

`src/design/chartTheme.ts` 是图表语义主题；图表与曲线按钮共用。T 蓝、R 橙、A 紫；同一通道 S/P 使用不同线型。曲线样式由通道、来源角色、偏振及比较索引解析。预留 measured / comparison 样式，不实现实测导入或多膜系比较。A 仍是原有无吸收模型下的数值残差，不改变吸收模型。

## 编辑约定

- 单击选格；方向键移动；Shift + 方向键扩展矩形选区。
- 双击 / F2 编辑；直接键入替换原值；材料可输入已有名称并使用候选列表。
- Enter 提交并向下，Shift+Enter 向上；Tab 提交向右，Shift+Tab 向左；边界夹紧到已有范围。
- Esc 放弃草稿；有效失焦提交；无效 Enter/Tab 保留编辑，无效失焦取消草稿并提示。
- 单元格选择态支持 Ctrl/Cmd+C/V；编辑态保留原生文本选择与剪贴板行为。TSV 粘贴不隐式创建膜层。
- 多行/多列粘贴整批校验并一次提交、一次撤销。材料必须已存在且可用于膜层，厚度有限非负；同一行若包含多个厚度表达，必须相互一致，防止静默覆盖。
- 选择态 Ctrl/Cmd+Z、Ctrl/Cmd+Y、Ctrl/Cmd+Shift+Z 走现有项目历史；编辑态保留文本撤销。macOS 原生菜单中膜系撤销的 Option+Cmd+Z 继续可用。撤销/重做后恢复表格焦点。
- 自动重算仍使用已有串行、仅采用最新结果的队列。工具只有文本草稿和选择状态，主工作台拥有唯一项目数据、历史、保存与计算权威。
