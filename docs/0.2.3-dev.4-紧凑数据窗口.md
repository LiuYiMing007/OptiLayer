# 0.2.3-dev.4 紧凑数据窗口（开发预览）

日期：2026-11-08。尚未发布正式 0.2.3。窗口视觉方向仍需用户试用确认。

本次修正了工具窗口沿用大面积 Dashboard 容器的问题。浏览器窗口从共享注册表读取宽度，膜层、环境、响应、组和膜堆等窗口按内容决定高度；桌面使用真正的 Tauri 工具窗口。窗口可移动、缩放、关闭后重开，共用主窗口项目和撤销记录。

| 窗口 | 默认尺寸（桌面内容区） | 组织方式 |
| --- | --- | --- |
| 膜层结构 | 490 × 270 | 横向膜层表，可切回原纵向编辑器 |
| 后表面膜层 | 590 × 250 | 独立背面视图，命令明确携带表面 |
| 材料 / 基底 | 240 × 410 | 搜索、来源筛选、分页窄列表 |
| 材料数据 | 480 × 240 | 独立波长/n/k 横表，资料说明默认隐藏 |
| 环境 | 360 × 385 | 对齐的两列参数表 |
| 光源 / 探测器 | 400 × 190 | 波长、强度/效率横表 |
| 组 | 360 × 180 | 组号、系数、膜层数横表 |
| 膜堆表达式 | 520 × 350 | 表达式、符号定义、预览和替换 |

浏览器兼容窗口保留拉伸能力，初始不强制填满高度；说明和元数据折叠。桌面已有布局首次迁移时保留位置并采用紧凑尺寸，之后继续记忆用户调整的尺寸。大型膜系与材料表在表内滚动；材料每页50项，n/k 每页32点，编辑表每页24点，不为几千个数据点生成庞大窗口。

## 操作与正确性

- 横向表保留基底向外编号，复用已有材料/厚度换算与批量粘贴校验。支持双击/F2、Enter/Tab、方向键、Shift 扩选、Esc、复制粘贴、撤销和重做。同一层重复厚度字段冲突时整次粘贴拒绝，避免部分写入。
- 组系数沿用已验证的比例调整逻辑，不重复乘系数；前后表面共用组定义。
- 表达式使用有界解析器，支持符号序列、括号重复、厚度倍数和 G 组指令。最多500层、16级嵌套。先预览再替换，替换校验当前膜层是否改变，一次撤销恢复。
- 材料目录点击条目打开数据窗；浏览数据不改变项目。编辑内置数据仍创建副本，保留原始库；完整 n/k 读取与材料校验在新数据窗可用。各工具仅获得只读目录能力，Workspace 写入仍由主窗口协调。
- 光源、探测器可新建、编辑和选用自定义响应；WHITE/IDEAL 为只读平坦参考。本征 R/T/A 与响应加权显示保持区分。
- TFD 新增原 QWOT 与原物理厚度、当前材料 n(参考波长) 的一致性提示。差异记录在项目导入记录中，导入后提示差异层数。不根据截图或冗余厚度字段拟合并覆盖材料，也不改变原物理膜厚。

## 核查结论与边界

实际用户对照文件存在冗余厚度与当前材料数据不一致的证据。具体文件、逐层数值及原件哈希报告仅保存在本机 `acceptance` 中，不上传 GitHub。原版对应的完整材料表和实际 R/T 数值仍待补充，不能声称已经完成与 TFCalc 曲线的逐点等价验证；TFD 中 TARGET 记录不当成原版计算结果。

重新检查771份本机存档 TFD：767份可导入，4份仍因原材料缺失而阻止，与此前数量一致；存档原件哈希未变。此检查是导入回归，不代表原版光谱逐点等价。

本次不实现自动优化、优化约束、针插入、变量材料、角度分布积分、光源相位、多环境切换或光学厚度优先规则。膜堆表达式是窗口草稿；生成后的实际膜层正常保存到项目，表达式草稿尚不写入项目格式。光学计算公式和材料常数未修改。
