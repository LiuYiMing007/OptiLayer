# 0.1.3 回传 Mac 说明

Windows 与 Mac 的开发目录不会自动同步。回传前保留 Mac 源码备份，退出应用。使用交付目录中的源码修改包，将其中相对路径的文件合并到 Mac TFC 源码目录。

## 修改范围

- `engine/main.py`：JSON 标准输入、输出和错误流统一 UTF-8，避免 Windows 默认代码页破坏中文。
- `engine/tests/test_process_encoding.py`：强制 GBK 环境的 UTF-8 进程通信回归测试。
- `engine/tests/test_engine.py`、`test_optics.py`、`test_workspace.py`：显式 UTF-8 读取测试资料；原测试和数值实现保留。
- `scripts/validate_engine.py`：显式 UTF-8；验收证据按产品版本和平台命名，不再覆盖旧版报告。
- `scripts/validate_workspace_release.py`：显式 UTF-8；工作区验收报告按版本和平台命名。
- `scripts/validate_user_workspace.py`：只复制原 Workspace；对全部项目执行打包引擎计算、保存、搬迁、复算和原件哈希核对。
- `scripts/stage_release.py`：修复 Windows 打包暂存目录私有权限，避免便携包无法读取。
- `src/App.tsx`：界面版本与 Windows Ctrl+S 提示。
- `scripts/build_windows.ps1`：加载微软 C++ 构建环境的一键脚本。
- `scripts/build_desktop.mjs`、`package.json`：Windows 默认生成便携包；macOS 保留原生 bundle 构建。
- `package-lock.json`：补全跨平台可选依赖，产品版本升级。
- `src-tauri/Cargo.toml`、`Cargo.lock`、`tauri.conf.json`：产品版本升级至 0.1.3，Rust 库版本保留。
- `.gitignore`：排除本机用户项目验收副本。
- `README.md` 和本版文档、证据：Windows 实测范围与操作说明。

未改写 `engine/optics.py`、`models.py`、`analysis.py`；没有 AI Agent 或优化功能。

## Mac 接收后验证

保留 Mac 自己的 `.venv`、`node_modules`、`src-tauri/target` 和 Mac 应用；不要用 Windows 构建目录覆盖它们。锁文件更新后在 Mac 运行 `npm ci`、`npm test`、`npm run validate:optics`，需要更新应用时运行 `npm run desktop:build`。Windows EXE 和引擎不能代替 Mac 应用。

源码修改包不含用户 Workspace。验收副本属于业务数据，若要回传，应退出应用后另行复制整个 Workspace，给它新名字，先在 Mac 打开复算再决定使用哪份数据，避免覆盖唯一原件。
