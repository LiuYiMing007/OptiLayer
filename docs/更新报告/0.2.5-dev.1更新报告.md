# 0.2.5-dev.1 开发预览更新报告

本版集中修复材料编辑窗口死锁、光谱纵轴范围及膜层表格显示问题，并核对整批 TFD 原始膜厚。它是开发预览版，不替换0.2.4正式版。

## 材料编辑窗口

关闭原生工具窗口实际执行隐藏，草稿尚在；旧逻辑却拒绝打开正在编辑的材料数据窗口，导致用户无法保存或取消。本版在目录点击材料、数据或新增时恢复原编辑窗口，保留输入，并提示先完成当前编辑。切换项目或退出时也定位材料数据窗口，而非错误地定位材料列表。

取消/保存后清理新建草稿标记，渲染器重新连接时校准编辑状态。浏览器兼容窗口的关闭和最小化改为隐藏界面，保留表单；不再因卸载组件丢失输入。正在编辑时删除仍须先完成编辑，不会假称已删除数据。

## 光谱纵轴

在原有“自动纵轴”“0–100%”外新增“自定义纵轴”。输入下限、上限，点击“应用范围”或 Enter；支持小数和负值范围，拒绝空值、无穷、上下限颠倒。范围仅影响显示，不影响计算输入及结果；手工范围更新不会重置横轴缩放。纵轴范围及膜厚显示模式是当前窗口设置，本阶段不写入项目格式。

## 膜层结构

横向和纵向表格都只保留材料、物理厚度、1/4光学厚度、组。删除光学厚度 n·d 的单独行/列。物理厚度固定两位小数，1/4光学厚度固定四位；编辑和保存仍保留完整数值，不将显示舍入写回项目。

重新映射移除列后的键盘选择、Enter/Tab、复制粘贴和分组字段，保持整块粘贴校验、撤销及自动计算。

## TFD 膜厚核对与显示口径

原版手册“Groups Window”（用户提供手册 PDF 第27页）说明：真实厚度 = Layers窗口厚度 × 组系数。此前计算核心保存实际厚度是正确的，但界面直接展示实际厚度，与原TFCalc组前厚度的口径不同。

本版默认显示“组前厚度（TFCalc）”，可切换“实际厚度（含组系数）”；组前编辑通过一次系数换算写入实际厚度。修改分组本身继续保持实际厚度，不悄悄改变膜系。系数为零时无法从实际零厚度反推出组前厚度，明确显示“—”并要求切换实际厚度模式，不编造值。

项目窗口原始导入记录新增逐层核对表，列出源组前物理厚度、源组系数及导入实际厚度。此表是导入时记录，不冒充后续编辑状态。

只读核对用户原771个TFD：767个可导入、4个因已知材料引用问题继续拒绝；共18,767层。其中75个文件使用非1组系数。以独立Decimal运算对照源文件，导入实际厚度最大差异为 `5.684341886080802e-14 nm`，还原组前厚度最大差异为 `2.842170943040401e-14 nm`。原件哈希全部不变；逐文件实验资料只保留本地，不上传。

**准确性边界：**这些结果证明文件中保存的物理厚度与组系数未被错误导入，不证明与原版TFCalc当前界面所有层都完全一致。用户报告所有膜系都有细微差别，目前尚未取得两端同层的精确读数作完整对照。手册还存在光学/物理厚度优先规则；本版继续保留源物理厚度，不猜测CONFIG字段、不自动改材料折射率、不按截图拟合厚度。不能把已确认的组显示口径差异宣称为所有细微差异的唯一原因。

## 验证与发布

本机69项Python、60项TypeScript、9项打包迁移、12项Rust测试及25项数值检查通过。Golden最大误差仍为 `7.838345368327282e-7` 个百分点。未修改Optical Core、材料常数、项目格式或数据库版本。

隔离界面验证：编辑输入后关闭→重新恢复草稿→取消→选择其它材料，未再次出现死锁；自定义纵轴70–85%已实际应用；两种表格格式符合要求。本机打包后的原生菜单、15个工具窗口、材料编辑器关闭/重开后完整121点草稿仍在的回归、材料库增删恢复、环境计算、目录显示和便携搬迁检查均通过。

发布提供Mac、Windows和双系统便携包及SHA-256。发布工具明确支持 `x.y.z-dev.N`，开发版标记为Prerelease且不设置为Latest。只替换程序目录，保留Workspace、Workspaces、.tfc；已有0.2.4数据可继续使用。物理SSD换盘符及所有显示缩放不由自动检查替代。
