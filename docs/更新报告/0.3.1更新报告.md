## 膜系自动优化：实测拟合与补偿

仍位于“分析 → 膜系自动优化…”，新增两种明确用途：

- **实测反推与补偿**：当前膜系为理论基准，拟合导入的实测 R/T，展示一组可解释的层厚偏差及下一炉补偿候选。
- **设计目标优化**：调整现有层厚接近目标曲线，不把候选厚度称为实际工艺测量值。

### 算法

- 支持最多256个所选膜层、10001个数据点；不再有旧版30层、500点限制。较大数据在搜索时最多均匀选取2001个原采样点，最终误差以所选波段全部数据复核，并显示搜索/复核点数。
- 以原理论厚度的百分比作为优化坐标，支持逐层、同材料、同组或整体共同偏差。逐层模式先粗扫整体漂移，再拟合材料共同偏差，随后逐层细化；使用可重复的多起点搜索，改善直接从原设计进入局部极小值的问题。
- 使用有界最小二乘并显式计算数值 Jacobian；导数探测不再被误记为已接受的最佳膜系。评估预算提高至30000次，运行预算可选20/60/120秒；桌面与开发桥另有300秒硬超时，支持真正停止子进程。
- 可设置厚度上下限与偏差约束，默认所选层±10%、偏差约束0.1。优化目标为光谱误差加相对厚度偏差惩罚；界面报告的 RMSE 是纯光谱误差，单位为百分点。约束越大越保守，0表示不加该惩罚。
- 默认拟合区间取数据、项目和膜层材料范围交集，可手动修改；基底、介质材料的范围仍单独提示。范围外数据保留、标灰并计入“未使用点数”，不伪称全波段都拟合到所显示的误差。

### 结果与 UI

- 统一的理论／导入数据／拟合光谱图，下方显示拟合区残差；未拟合区间灰色遮罩。
- 显示初始/最终 RMSE、误差降低、时间、点数、实际评估次数和预算终止状态。
- 膜厚表展示理论厚度、拟合厚度、相对偏差、补偿厚度、局部灵敏度及达到上下限的标记；支持按偏差排序。
- 局部灵敏度使用“原理论厚度变化1%引起的光谱 RMS 变化”，不是故障概率。数值有效秩以最大奇异值的 `1e-3` 为相对阈值，提示相关/难辨识方向，不作为精确置信区间或唯一坏层判断。
- 可导出完整 JSON 拟合报告和膜厚 CSV；导入数据、参数与结果保留在当前分析窗口，应用前不写回原项目。关闭/切换项目之前请导出需保留的报告；浏览器内置下载落盘依赖宿主支持，桌面使用原生导出流程。
- “应用拟合膜系”和“应用补偿候选”分开，均核对完整项目/作用域并纳入撤销历史；先前已修改的项目不能被过期结果覆盖。

### 补偿边界

补偿使用 `d下一炉 = d理论² / d拟合`，仅表达同类**乘性厚度偏差可重复**的假设。它不是已经测得的真实层厚，不是唯一正确配方，也不能修复已镀成品。n/k、测量条件、仪器分辨率及基底模型均可能造成曲线差异；拟合良好也不能证明误差全部来自膜厚。零厚度或无法形成有效补偿时不提供补偿候选。

数值方法背景参考 [SciPy 有界最小二乘](https://docs.scipy.org/doc/scipy-1.16.2/reference/generated/scipy.optimize.least_squares.html)。生产计算仍调用原 Optical Core。
