# TFC 0.2.0 更新报告

本版完成 TFCalc 材料／基底数据提取、目录检索和真实 n/k 计算链路，并更新两端应用图标。保留 0.1.5 的光谱主窗、独立工具窗口和便携工作区；没有开发 AI Agent 或膜系优化。

## 材料与基底

| 原目录 | 记录数 |
|---|---:|
| MATERIAL | 372 |
| SUBSTRAT | 417 |
| SCHOTT | 201 |
| SOPRA | 221 |
| 合计 | 1211 |

1,186 项通过可用数据检查。25 项原始记录为空、截断、损坏或含负 k，已登记到“待核查”目录并禁止用于计算，避免伪造缺失常数。详细文件及原因见 [导入验收](../0.2.0-材料与基底导入验收.md) 和 [完整来源清单](../0.2.0-材料数据清单.json)。

同名不同来源分开保存，精确等价数据标注重复关系而保留原名称。每条保留相对来源路径、原始文件 SHA-256、编码、备注、原始波长范围与完整 n/k 或公式系数。两端应用内置完整目录，无需原 TFCalc 文件夹、联网或系统 Python。

## 检索界面

材料与基底共用紧凑的“检索表格 + 数据详情”布局，提供多关键词／中文名搜索、来源、用途及状态筛选、每页 50 行、↑↓ 和 Enter／双击应用。显示 n/k 预览、波长范围、来源备注与校验信息；基底窗口直接设为当前基底。项目保持完整材料快照，目录更新不改变旧项目。

没有把 1,211 项全部复制进项目；多窗口只传目录摘要，选择时才载入未降采样的完整数据。自定义常数编辑、JSON 导入和保存到工作区共享库继续保留。

## 计算及数据正确性

- 原有无吸收常数特征矩阵路径保留，原 Golden、用户 380 nm 算例及 25 项数值验证通过。
- 新增纯材料求值模块，支持逐波长 n/k 和当前目录使用的 Sellmeier、Cauchy、Hartmann 公式，n、k 全部参与计算。
- 色散／吸收使用稳定的后向散射递推，验证金属薄层、厚金属、多层膜、斜入射 S/P 和吸收基底，与独立 tmm 对照。tmm 仅供测试，生产程序不依赖它。
- 光学厚度与 QWOT 按当前参考波长的 n 换算，计算始终使用物理厚度。
- A=100−R−T 在吸收模式为膜系吸收，在无吸收模式为数值残差；吸收时不将真实 A 误称能量误差，也不裁剪或归一化掩盖结果。
- 表格采用 TFCalc 线性插值、范围外最近端点规则并显示提示；公式范围外或当前波长无物理解时拒绝计算，不擅自改动来源数据。

仍不支持负 k 增益、吸收入射介质、各向异性、基底背面或非相干厚基底。原材料库不是实际镀膜工艺的重新认证数据。完整模型、边界及字段见 [材料与计算设计](../0.2.0-材料目录与计算设计.md)。

## 图标与其他参考

原创图标采用薄膜界面、法线以及入射／反射／透射光线，生成 Mac icns、Windows ico 和 PNG；矢量源为 `assets/tfc-icon.svg`。没有复制原 TFCalc 程序或图标。

原目录的照明、探测器、角度分布和示例膜系适合后续参考。本版记录其用途，没有冒充已实现照明加权、原 TFD 全格式或优化功能。

## 验证与发布

本机完成 39 项引擎 Python、25 项 TypeScript、4 项打包 Python、10 项 Mac Rust 及 25 项数值检查。Mac 正式构建中完成目录资源读取、吸收／色散计算、保存／搬迁／精确复算、菜单与七个真实工具窗口 IPC 检查；材料搜索与基底操作另用隔离工作区实测。

正式标签触发同一套 macOS / Windows CI；两端均必须通过测试、构建、打包资源验收、七个工具窗口真实前端 IPC、菜单及便携工作区搬迁检查，之后才创建 Release 和双系统合并包。实际每端结果保存在对应 Actions `checks-*` 中，包含新增 `catalogue.json`。Windows 人工视觉、显示缩放、物理 SSD 多设备往返不在自动检查覆盖范围内。

下载文件沿用原方式：

- `TFC-0.2.0-macOS-arm64.zip`
- `TFC-0.2.0-Windows-x64-portable.zip`
- `TFC-0.2.0-macOS-Windows-portable.zip`
- 每个 ZIP 配一个 `.sha256` 校验文件，不是额外软件版本。

## 使用与升级

1. 退出旧程序，备份现有便携项目中的 `Workspace`、`Workspaces` 和 `.tfc`。
2. 从新包复制 `macOS`／`Windows` 程序子目录覆盖旧程序，保留原数据目录。新包不含用户 Workspace。
3. 打开程序，菜单“窗口 → 材料”，检索所需材料并“加入当前项目”；膜层结构窗口选择该材料。
4. 菜单“窗口 → 基底”，检索来源与名称，点“设为当前基底”。基底使用同一项目状态并自动更新光谱。
5. 检查材料适用范围、参考波长、角度和偏振，计算后保存项目。

旧常数项目保持原计算，不会自动被真实库替换。使用新增色散／吸收模型的项目应在 0.2.0 或更高版本打开；0.1.x 无法计算这些新模型。搬迁仍需关闭应用并保留整个便携项目。
