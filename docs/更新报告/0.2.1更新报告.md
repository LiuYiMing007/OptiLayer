# TFC 0.2.1 更新报告

本版修复 Mac 工作区不可用导致材料目录不可见、材料与基底缺少编辑入口，以及未修改项目反复要求保留更改的问题。保留 0.2.0 的计算核心、原始材料数据和 Workspace v1 格式。

## 工作区与目录

在用户电脑发现实际运行路径包含 macOS AppTranslocation。旧版误将隔离目录作为便携项目根目录，无法访问真实 Workspace；前端又等待工作区成功后才加载材料。现在明确识别隔离启动和 Applications 中缺少项目标记的启动，通过“工作区设置 → 选择便携项目位置…”选择实际 TFC 文件夹或已有 Workspace。正常便携项目仍按相对路径定位。断盘或已记住的工作区缺失时不静默创建空数据。

材料目录独立加载，无工作区也能检索 1211 项记录，其中 1186 项可用、25 项隔离待核查。没有重新提取或修改原始光学常数。修复成功重连后残留旧错误，以及 .DS_Store 等无害普通元数据阻碍新建工作区的问题。

## 材料与基底编辑、文件位置

- 支持名称、用途、来源、常数 n/k、逐波长三列表格及色散公式系数/范围编辑，保持数值精度；表格可粘贴 Excel 三列。
- 内置记录用“编辑副本…”，原件保留；自定义条目直接编辑。保存写共享库和当前项目，当前项目引用一起更新，作为一次历史操作可撤销；历史项目不会自动改变。
- 校验非数值、缺列、非递增波长、负 k、无效色散范围；失败保留编辑内容，跨窗口过期数据拒绝覆盖。未提交材料草稿时，切换项目或退出会返回编辑窗口，提示先保存或取消。
- “打开数据文件夹”显示当前 Workspace/materials。catalogue/TFCalc-0.2.0.original.json 为完整原始目录快照，custom/ 下是可读名称加哈希的 .material.json 文件。SQLite 为权威存储；外部修改 JSON 后需手动导入，不自动读取覆盖。
- 单个恢复材料文件可直接导入；批量导入先整体校验，避免中途失败导致半批内容。膜层材料选择支持可读名称，并保留稳定内部标识。

## 修改保护交互

仅在项目确有未保存修改、且新建/打开/切换工作区/退出将丢失修改时显示紧凑对话框。工具窗口打开、查看目录、光谱计算、未修改新项目不要求确认。采用稳定内容比较，避免 JSON 键顺序造成误判。提供“取消 / 不保存 / 保存并继续”，保存失败不继续破坏性操作；支持 Esc、键盘焦点约束，桌面退出避免浏览器原生确认重复出现。

## 验证

本机通过 43 项引擎 Python、29 项 TypeScript、4 项打包 Python、11 项 Mac Rust 和 25 项数值检查；Golden 最大误差约 7.84e-7 个百分点。Optical Core、原始材料目录校验及 Golden 未改动。

Mac 打包程序通过菜单、多窗口真实前端 IPC、无工作区目录读取与完整材料/基底编辑器渲染、实际打包引擎材料编辑/恢复文件、保存/搬迁/精确复算和便携路径检查。隔离验收副本中实测工作区重新选择、1215 项目录搜索、AG 完整数据编辑保存、保存并继续和未修改新建不重复提示。截图见 docs/v0.2.1-mac-*.png。用户原 Workspace 未作为验收写入目标。

正式发布由不可变 v0.2.1 标签触发。只有 macOS 和 Windows 同一套构建、测试、打包内资源及真实窗口 IPC 检查通过，才创建 Release。Windows 人工视觉/显示缩放和物理 SSD 往返仍需实际设备检查，自动验收不代替这些项目。

## 升级与下载

沿用 Mac arm64、Windows x64 便携包、双系统合并便携包，各附 SHA-256 校验文件。退出旧程序并备份数据，仅更新 macOS / Windows 程序目录，保留 Workspace、Workspaces 和 .tfc。发布包不包含用户工作区。

Mac 如仍提示未连接，打开工作区设置，选择固态盘中的实际 TFC 文件夹或原有 Workspace；不要为恢复已有数据另建空工作区。

没有开发 AI Agent、膜系优化、新材料物理模型或数据格式迁移。
