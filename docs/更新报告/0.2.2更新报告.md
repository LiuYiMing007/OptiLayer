# TFC 0.2.2 更新报告

本版完成 Windows 发布前验证，改进便携工作区的数据位置可见性，并扩展真实 TFCalc 文件导入。保留经过验证的 Optical Core、材料原始光学常数和数值 Golden；没有开发 AI Agent 或膜系优化。

## 工作区与实际文件

主窗口“数据位置”可查看所选工作区完整路径，直接打开工作区及全部七类数据目录：

| 文件夹 | 内容 |
|---|---|
| projects | 保存的膜系项目 JSON 副本 |
| materials/catalogue | 完整原始材料与基底目录 |
| materials/custom | 保存过的材料编辑副本 |
| spectra | 与项目输入一致的已保存光谱 |
| database | SQLite 项目和共享材料数据库 |
| imports | 导入资料与原件归档 |
| exports | 导出文件 |
| config | 工作区配置 |

工作区在首次连接后创建，新膜系保存后才生成文件；空的导入、导出或配置目录不代表数据丢失。材料与基底共用材料库，不重复建立两套状态。

修复 Windows 中文迁入报告受系统默认编码影响而写入失败的问题，所有报告统一 UTF-8，归档文件名统一跨平台相对路径。打开资源管理器前转换 Windows 文件系统规范路径，保留中文、空格和网络共享路径。目录验证在中文路径的副本上完成保存、搬迁、重新载入与复算，并核对真实资源管理器窗口位置。

移除旧版机器全局 project-location.json 的自动恢复与写入，避免不同安装误用其它项目位置。便携工作区继续按项目内相对路径定位；Mac 隔离启动无法识别实际位置时，需明确选择 TFC 项目文件夹，不会自动连接其它安装或验收目录。

## TFCalc 导入与项目查找

支持严格 UTF-8 / GB18030 解码、原始物理膜厚与分组系数归一化、膜层与基底按各自材料目录准确解析。保存文件来源、编码、材料映射、原始层参数及导入说明；项目窗口提供搜索与分页。

用户提供的 771 个 TFD 中，621 个完成解析、计算、保存、载入和精确复算；150 个因有限厚基底、背面膜系或缺失/乱码材料等原因明确拦截，没有静默丢层、忽略背面或替换默认材料。包括其它资料在内的 812 个原文件保持 SHA-256 不变，归档仅保留在私人工作区，不进入程序发布包。[完整兼容性说明](../0.2.2-TFD实际兼容验收.md)。

导入失败显示文件与具体原因，保留并标明原项目；切换项目后重置光谱视口，同一项目连续编辑保留缩放。

## 验证与边界

52 项引擎 Python、34 项 TypeScript、8 项打包/迁入 Python、12 项 Rust、25 项数值检查通过。数值 Golden 最大误差仍为 7.838345368327282e-7 个百分点。

macOS Apple Silicon 和 Windows x64 均验证打包内材料目录、材料编辑数据、中文 TFD、组系数、错误拦截、菜单、七个真实工具窗口 IPC、保存及搬迁精确复算。Windows 目录检查通过 Shell COM 核对工作区根目录与七个数据目录的目标窗口。

[双平台发布前验收运行](https://github.com/LiuYiMing007/tfc-workbench/actions/runs/41846947673)，验证源码 `6696037e85bed779feaeb5be6a825baf51f497a5`。其中 [Windows 目录窗口验收](../v0.2.2-windows-ci-workspace-folders.json)、[Windows 材料验收](../v0.2.2-windows-ci-catalogue.json)、[Windows TFD 验收](../v0.2.2-windows-ci-tfd-import.json) 与各平台检查 JSON 随代码保存。正式发布已由 [程序包来源与完整性核对流程](https://github.com/LiuYiMing007/tfc-workbench/actions/runs/41853009719) 完成。

实际发布来源：Windows 使用 `v0.2.2` 标签构建并验证的程序包；Mac 使用上述成功预检运行的 CI 程序包。Mac 构建源码与正式标签严格比较，仅有 README/docs 文档差异，程序代码相同。Mac 标签流程首次因云端 arm64 机器容量不足未能分配执行机器，未记为通过；采用已验收程序包后停止了排队重试。另以相同标签程序源码完成本机 Mac 构建、签名及全部打包检查。

三个程序包及三个校验文件均已核对发布端 SHA256，并与本机已检查的归档逐一一致。保留不可变 `v0.2.2` 标签；没有覆盖任何旧标签或旧版资产。[发布溯源与校验记录](https://github.com/LiuYiMing007/tfc-workbench/blob/main/docs/v0.2.2-release-provenance.json)。

本轮不等于全部 TFCalc 计算设置与原版曲线逐一对照验证，仍不支持双面膜系、有限厚基底、反向入射和变量/混合材料。物理 SSD 更换盘符、双机往返、显示缩放及人工鼠标交互不冒充为本轮自动验证。macOS 使用临时签名，未作 Developer ID 公证；Windows 未作商业代码签名。

iPhone 查阅框架仍为独立预览，未作为 iOS 正式安装包或真机验收通过发布。

## 下载与升级

提供 macOS 包、Windows 便携包、双系统合并包及各自 SHA256 校验文件。压缩包说明采用 ASCII 文件名 README.txt，内容列出全部数据目录。

将整个 TFC 文件夹放在可写位置或固态盘上，分别启动 macOS/TFC.app 或 Windows/TFC.exe。升级只替换程序子目录，保留原 Workspace、Workspaces、.tfc；旧数据可在工作区面板“迁入旧工作区（复制）”，不要用空工作区覆盖。关闭软件后再复制或搬迁整个 TFC 文件夹。
