# TFC 0.2.2 优化报告（开发验证，尚未正式发布）

用户反馈下载目录没有数据文件、TFD 导入失败但仍显示旧曲线。本次直接改进定位隔离、文件可发现性和失败反馈，不更改 Optical Core、材料数据或项目格式。

## 已实现

1. 取消机器全局 project-location.json 的自动恢复和写入，解决不同安装/验收程序误共享根目录。正常便携启动继续使用当前项目内相对路径；显式选择只作用本次会话。隔离启动无法确定原位置时需明确选择，不静默回退。
2. 主光谱窗口常驻“数据位置”入口；工作区设置改为紧凑属性布局，列出工作区、膜系项目、材料与基底、保存光谱、导出文件的完整路径，并可分别打开对应目录。原始目录与编辑副本、项目保存后才写文件等规则在界面说明。
3. 导入失败显示文件名、具体原因和“当前项目未被替换，曲线仍属于原项目”，提供重新选文件入口。失败不会清空原项目或把原曲线冒充导入结果。菜单明确标注 TFD 参考子集。
4. 压缩包说明使用 ASCII 文件名 README.txt，避免不同解压器按不同编码解释中文文件名产生乱码；合并包支持此文件跨平台换行规范化与去重。
5. 验收使用实际 Tauri 编译配置 identifier 隔离；不再仅修改 Info.plist。

## 尚未实现与边界

没有宣称完整 TFCalc TFD 格式兼容。AIR/GLASS 之外的环境、双面结构和其它旧格式语义仍需原文件与来源资料逐项验证；不能仅移除检查后套用默认光学常数。已向用户询问刚才导入失败文件的路径，以便后续针对实际文件扩展。材料库 1211 项数据继续可用，与 TFD 文件兼容范围是两件事。

本次未移动用户 Workspace，未覆盖 Downloads/TFC 内的程序或数据；上一轮误写定位已备份并清除。0.2.1 标签及其正式包保持不变。

## 验证状态

本机测试：44 项引擎 Python、29 项 TypeScript、5 项打包 Python、11 项 Mac Rust、25 项数值检查通过。新增回归覆盖不支持环境导入不修改原项目、错误包含具体环境，以及 README.txt 合并去重。Mac 正式构建与打包资源/菜单/工具窗口/工作区搬迁检查执行后记录在 docs/v0.2.2-*.json。

当前仅准备开发验证包，不创建正式版本标签；Windows 本轮构建以实际 Actions 状态为准。

Mac 实际界面验收已通过：编译时 QA identifier 隔离，旧的错误定位记录被忽略；选择便携项目后能连接；正式与 QA 定位配置哈希均未改变，错误项目未生成 Workspace；不支持的 TFD 显示文件名和原曲线所属项目；保存膜系后，“打开”准确定位至对应 projects 目录。见 v0.2.2-mac-ui-check.json 与两张 Mac 截图。
