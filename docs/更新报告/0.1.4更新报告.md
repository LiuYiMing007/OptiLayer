# TFC 0.1.4 更新报告

发布日期：2026-11-01。版本主题：工作区默认跟随便携项目文件夹。

## 解决的问题

0.1.3 会在每台电脑的系统目录保存一个绝对工作区位置。即使程序跟着固态 U 盘移动，另一台电脑仍可能使用自己的默认目录或旧选择，导致数据散落在不同电脑。

0.1.4 将定位规则改为：**从程序所在项目文件夹定位 Workspace，在项目内保存相对位置，不再根据各台电脑的旧偏好选择默认工作区。**

详细操作见 [便携项目使用说明](../0.1.4-便携项目使用说明.md)。

## 使用方式

```text
TFC/
├── tfc-project.json          便携项目标识
├── macOS/TFC.app            Mac 程序
├── Windows/TFC.exe          Windows 程序，连同 engine 目录
├── Workspace/              默认数据：项目、材料、光谱、数据库
└── .tfc/                   工作区相对位置设置
```

Mac/Windows 下载包采用同一个 TFC 外层结构。要共用数据，将两个包的程序子目录合并到同一个项目文件夹，保留一份 Workspace。首次启动自动建立项目内 Workspace；关闭后把整个 TFC 文件夹搬到固态 U 盘或其它可写位置，重新启动便会按项目内的相对位置寻找数据。

在源码目录启动桌面程序时，以源码项目根目录为便携项目根；本机 `release/TFC.app` 同样会沿父目录找到根部项目标识，默认使用本项目 `Workspace/`。

## 本版变化

- 新增项目标识 `tfc-project.json`，将“程序所属的项目文件夹”与 Workspace 自身的 `workspace.json` 区分。
- Mac 从 `.app` 外的项目目录定位，数据不写入应用包；Windows 从 EXE 所属项目目录定位。结果不依赖启动时的当前目录。
- 最近选择保存在项目内 `.tfc/workspace-selection.json`，内容是 `workspace_relative`，没有电脑用户名、绝对盘符或挂载路径。
- 工作区面板显示项目文件夹、当前工作区与项目内相对位置；顶部明确标为“项目内”。
- 新建和打开操作限定在当前项目内。旧版或其它位置的数据使用“迁入旧工作区（复制）”，复制到项目的 Workspaces 子目录，原件保留；不静默覆盖已有目标。
- 迁入使用 SQLite backup API，检查数据库完整性；拒绝目录嵌套复制、未来版本、链接逃逸以及缺少数据库却残留恢复副本的情况。
- 记住的工作区缺失、格式不支持或项目不可写时明确报错，不自动改用其它磁盘或系统用户目录。
- 便携发布包只含程序、项目标识与说明，不包含用户 Workspace；升级时只替换程序子目录，保留数据和 `.tfc`。
- 当前本机已有 3 个项目已复制到项目根目录 Workspace，原本机数据保留。此项属于本机迁移操作，不会把用户数据打进 GitHub 下载包。

## 验证

- Python：32 项通过；TypeScript：4 项通过；光学数值：25 项通过。
- Mac Rust 路径测试：7 项通过，覆盖同项目 Mac/Windows 路径、整体移动、相对选择、丢失目录、错误版本、外部路径及链接逃逸。Windows 相同测试除 Unix 链接项外执行 6 项。
- Mac 实际便携包：运行真实客户端的只读定位入口，从无关工作目录启动，确认默认项目/Workspace；保存项目、移动整个项目、重新定位并精确复算通过。
- 原有数值算法、Golden 和材料/膜系模型保留；不因位置调整重写 Optical Core。
- Windows 0.1.4 的在线构建与包级定位检查由 GitHub Actions 执行，实际状态以 Actions 与本版验收记录为准，不能以 Mac 结果替代 Windows 实测。

## 升级与边界

0.1.3 的旧工作区不会自动丢弃或合并。请在 0.1.4 面板点击“迁入旧工作区（复制）”，选择包含 workspace.json 的旧文件夹，确认项目清单后使用项目内副本。之后只维护一份主工作区，避免两份数据各自更新。

移动前关闭应用，复制整个 TFC 项目文件夹，安全弹出磁盘；升级不要删除 Workspace、Workspaces 或 .tfc。项目目录不可写时，请把整个文件夹放到可写位置后运行，不能直接依赖只读安装镜像。

本版的自动化搬迁是目录移动测试，并非真实重新分配 Windows 盘符、热拔插、异常断电或物理断网测试。Windows 仍需要 WebView2；应用未签名/公证。不支持两台电脑同时写入同一 Workspace。

未开发 AI Agent、膜系优化、吸收/色散或同步功能。
