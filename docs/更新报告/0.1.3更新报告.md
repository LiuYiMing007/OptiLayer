# TFC 0.1.3 更新报告

发布日期：2026-10-31。版本主题：Windows 便携交付、UTF-8 兼容修复与 Mac 回传验证。

## 本版完成了什么

0.1.3 将 0.1.2 准备的跨平台基础落实为实际 Windows x64 便携程序，并将修改合并回 Apple Silicon Mac，分别构建、测试和验证。计算核心继续保留，没有引入 AI Agent 或膜系优化。

### 1. Windows 便携程序实际交付

- 在 Windows 10 19045 x64 完成前端、Rust 与 Python 引擎构建。
- 程序和完整 onedir 引擎一起分发，运行计算不需要用户安装 Python、Node 或 Rust。
- Windows 默认生成便携目录，提供微软 C++ 构建环境加载脚本。
- 保存快捷键提示适配 Windows 的 Ctrl+S；Mac 保持 ⌘S。
- 便携目标电脑仍需已有 Microsoft Edge WebView2；本版没有交付已验收的离线安装器。

### 2. 修复 Windows 编码与分发问题

- JSON 进程标准输入、输出与错误流明确使用 UTF-8，避免系统代码页破坏中文。
- 测试和验收脚本显式按 UTF-8 读写，增加强制 GBK 环境的通信回归测试。
- 数值和工作区报告按版本、平台命名，避免覆盖历史证据。
- 补全跨平台可选依赖，已有依赖版本未升级。
- 修复 Windows 暂存目录私有权限导致移出的便携程序对桌面用户不可读的问题。

### 3. 在 Windows 介质和桌面界面验证

原有 3 个 Mac 项目的副本完成打开、计算、保存项目及光谱、目录搬迁和精确复算。Windows 端同时完成 E: NTFS 目录测试、F: exFAT 固态 U 盘引擎及桌面程序测试；桌面保存和重启后重新打开通过。原工作区文件哈希不变，未在唯一原件写入。

### 4. 合并回 Mac 并重新构建

合并前备份 Mac 原源码、0.1.2 应用和工作区。回传修改包哈希验证通过，无本地修改冲突。Mac 独立运行测试、数值检查并生成 0.1.3 应用和 DMG。

Windows 回传的 3 个项目，在 Mac 打包引擎中完成保存、搬迁和精确复算；与 Windows 归档光谱逐项比较，最大差异为 **1.1368683772161603×10⁻¹³ 个百分点**，低于 10⁻⁸ 的验收容差。同一 Mac 引擎搬迁前后结果逐值一致。

Mac 原生界面打开“330-450AR”、计算 121 点、保存光谱、退出重启后重新打开与复算均通过。Mac 原工作区及 Windows 回传原件哈希保持不变。

## 当前交付位置

以下路径相对于项目根目录，已按本次目录清理后的结构整理：

- Mac 应用：`release/TFC.app`。
- Mac 安装镜像：`release/TFC_0.1.3_aarch64.dmg`。
- Windows 程序：`release/Windows/TFC/TFC.exe`，必须保留旁边完整 `engine` 目录。
- Windows 压缩包：`release/TFC-0.1.3-Windows-x64-portable.zip`。
- 可回退版本：`backups/pre-0.1.3-merge-20261031-094113/`。

程序和 Workspace 是独立的。Mac、Windows 使用各自程序，顺序打开同一套 Workspace；不要同时写入。数据移动时复制整个工作区，不能仅复制数据库或单个 JSON。

## 尚待实测与已知限制

- 实际更换 Windows 盘符、物理断网、热拔插或异常断电。
- 在缺少 WebView2 的电脑运行或离线安装。
- 同一物理 SSD 在当前 Mac 与 Windows 间插拔、写入再往返；现已完成从 Windows 回传到 Mac 的数据兼容与光谱比对。
- Mac 未做 Developer ID 签名与公证，Windows 程序未签名。
- 没有实现 AI Agent、优化器、真实色散/吸收、独立浏览器版或同步冲突合并。
