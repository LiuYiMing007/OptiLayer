# 0.2.5-dev.2 材料窗口回归修复

本版修复 dev.1 的材料/基底界面回归，保留 0.2.4 的紧凑列表与逐波长 n/k 数据表，不重做材料管理体系。

## 修复内容

- 材料数据窗口中，提示与编辑器原来横向争抢空间；改为纵向排布，移除无关的全局恢复提示。表格的固有宽度不再撑大属性区域，输入框、标题及保存/取消按钮保持在窗口内。表格独立横向滚动，顶部操作条在小窗口中保持可访问。
- 查看材料默认显示其原有完整数据：逐波长表、常数记录或色散公式，按实际模型展示，不将已有逐波长数据改为常数。只有主动点编辑或新增才进入编辑器。新增默认使用逐波长表。
- 未结束的草稿不再劫持其他材料的查看操作。关闭编辑窗口后，可打开其他材料的完整数据；“继续编辑”恢复原输入，“放弃编辑”解除编辑状态。原草稿组件及编辑用途保留，避免切换查看导致未保存输入丢失或把膜层材料误设成基底。删除、新建及切换项目仍保护未保存草稿。
- 统一隐藏旧“自定义”“自定义材料”“自定义基底”集合标签；记录仍在全部列表中，不删除用户新增材料，不改变其文件及来源信息。内置参考项目所需的四种计算材料不因此从已有项目中删除。
- 保留 dev.1 的纵轴范围设置、膜厚显示精度与组前/实际厚度切换；Optical Core、n/k 常数、项目格式和数据库版本未变。

## 验证范围

本机 69 项 Python、61 项 TypeScript、9 项打包/迁移、12 项 Rust 及 25 项数值检查通过。Golden 最大误差仍为 7.838345368327282e-7 个百分点。

原生窗口自动验收增加实际控件边界检查：默认 480×240 的小窗口中，编辑器占满可用宽度、名称输入及所有属性标签不超出视口、顶部取消按钮可见；不能仅凭隐藏文本框存在就判定界面可用。另验证 121 点银材料编辑 → 关闭/恢复 → 查看另一材料 → 恢复完整草稿 → 取消 → 回到完整数据表。

使用隔离测试工作区，未覆盖个人数据。发布前执行本机打包程序的菜单、多窗口、材料增删恢复、环境、保存搬迁和可见文件夹检查。Windows 由标签构建任务在 Windows 运行器上验收；具体结果以该任务及发布页面为准，不替代全部实体机显示缩放验收。
