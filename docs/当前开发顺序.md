# 当前开发顺序（0.3.0）

0.3.0 按用户本次授权仅新增膜系自动优化和 AI Agent 雏形，入口均在分析菜单。功能、使用方法及验证边界见 [0.3.0 更新报告](更新报告/0.3.0更新报告.md)。

优化器支持固定材料/层序、逐层物理厚度上下限、目标 R/T 等权局部拟合、候选预览和可撤销应用；AI 支持 Responses API 配置、读取项目、真实计算、膜厚候选和工具调用记录。暂不扩展为全局结构优化、组约束、多环境联合优化或完整自动设计 Agent。

下一步先完成用户所选真实模型服务连通及 Windows 0.3.0 原生验收，再根据真实使用结果决定后续功能。原版 TFCalc 数值对照、25 项材料异常来源补齐、物理 SSD 双系统往返、显示缩放、多显示器及 iPhone 真机离线仍需独立验证。

原 0.2.0 顺序中列出的材料编辑、背面膜层和有限基底已完成，不再列为待开发。Rust/WASM、工艺系统等不属于本次范围。
