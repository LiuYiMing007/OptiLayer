# 当前开发顺序（0.2.0）

0.2.0 以导入真实材料／基底为中心：1,211 项登记、1,186 项可用、25 项待核查；材料和基底目录改为检索表格；新增完整色散和吸收计算、来源追溯及原创图标。详见 [本版报告](更新报告/0.2.0更新报告.md)、[数据验收](0.2.0-材料与基底导入验收.md) 和 [材料设计](0.2.0-材料目录与计算设计.md)。

下一步优先用用户真实膜系、实测光谱与 TFCalc 相同参数进行逐项对照，确认工艺适用性。补齐 25 项原始数据异常，应取得完整原文件或可追溯来源，不猜测缺失数据。然后完善材料数据编辑与来源版本管理，以及基底背面／非相干厚基底模型，并分别建立独立验证。

保留跨平台、离线优先、便携 Workspace、光谱主窗及原生工具窗口。Windows 人工显示缩放、多显示器布局、物理 SSD 双系统往返属于后续真机验收。当前不开发 AI Agent、膜系优化或第二套 Rust/WASM 计算内核。
