# 当前开发顺序（0.1.2 基础架构后）

项目定位：跨平台、离线优先、AI 原生的光学薄膜设计与镀膜工程软件。原有八个业务系统保持不变。

1. 当前：确认 Workspace 的新建、选择、旧版复制迁移、整目录搬迁和第一条专业链路稳定；跑通真实 Windows 构建与离线运行。保持既有 Golden / 独立 TMM 测试。
2. 下一阶段：材料/基底数据来源、适用波段与实测光学常数；在明确范围内增加色散/吸收和新的科学验证。先完成专业可信度，不急于堆 UI。
3. Rust Core 评估门槛：用同样本验证 native 与 WASM，再验证未来实际优化任务的生态；达标后一次性切换唯一生产实现，保留 Python 作为验证资产。
4. 后续才进入目标定义、膜厚优化、制造约束、容差与敏感度。
5. AI Agent 通过 Application 工具层接入，断网不影响专业功能；密钥不进入工程/Workspace。
6. 更后期再实现实测比对、工艺记录与建议系统。

目前没有实现 AI Agent、优化器、纯浏览器 WASM、PWA、云同步、多人协作或自动工艺修正。
