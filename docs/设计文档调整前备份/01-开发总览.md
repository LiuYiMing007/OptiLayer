
**一款跨平台、离线优先、AI 原生的光学薄膜设计与镀膜工程专业软件。核心光学计算与 AI 解耦，支持 macOS、Windows，并为浏览器运行和便携式工作环境预留能力。**

整体可以分成下面 **8 个核心系统**。

| **系统**     | **核心功能**         | **优先级** |
| ---------- | ---------------- | ------- |
| ① 项目系统     | 管理膜系、设计文件、计算结果   | ★★★★★   |
| ② 材料系统     | n/k、色散、基底、膜料     | ★★★★★   |
| ③ 膜系编辑器    | 创建和编辑多层膜结构       | ★★★★★   |
| ④ 光学计算引擎   | R/T/A、角度、偏振等     | ★★★★★   |
| ⑤ 光谱分析     | 曲线、指标、对比、实测数据    | ★★★★★   |
| ⑥ 膜系优化器    | 自动优化膜厚/结构        | ★★★★    |
| ⑦ AI Agent | 自然语言设计、分析、调用工具   | ★★★★    |
| ⑧ 工艺系统     | 实测→分析→工艺修正→历史数据库 | ★★★     |
**AI 是操作软件的智能层，而不是软件的计算核心。**

即使 API 断网了，你的软件依然应该能编辑膜系、计算光谱、优化膜系；接入 AI 后，只是让它变成一个**会自己使用这些专业工具的 Agent**。

**兼容性目标**：逐步支持 TFCalc `.tfd` 膜系文件的导入/导出，用于已有膜系迁移和计算结果交叉验证；不以复刻 TFCalc 为产品目标。
